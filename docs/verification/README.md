For a requested feature, first identify the user's decision, the record owner, the facts read, the change made and the downstream effects. Record which policies determine the outcome, who can approve it, and the evidence returned when a change fails halfway. Use the nearest departmental acceptance example and one journey above. Treat a new country's accounting, employment, safeguarding or privacy rules as a local configuration and validation exercise, with an accountable church officer.
