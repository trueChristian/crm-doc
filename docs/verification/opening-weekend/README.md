# Opening weekend in a migrated congregation

Use one fictional congregation and one reporting cutoff to test whether the registrar, communications lead, treasurer and reviewer can reproduce each other's handoffs. Run the exercise in an isolated organization. The records below are independent of a particular application, storage model, accounting jurisdiction or church constitution.

| Order | Workpaper | Decision it supports |
| --- | --- | --- |
| 1 | [Import and certify the register](register.md) | Can the clerk preserve shared contacts, incomplete dates, distinct identities and the original roll after a late correction? |
| 2 | [Release the first bulletin](bulletin.md) | Can the communications lead reconcile people, endpoints, suppressions and actual deliveries after the audience changes? |
| 3 | [Close the first settlement](settlement.md) | Can finance explain one deposit that contains shop proceeds and two gifts, including a later partial refund? |
| 4 | [Recover and sign off](recovery.md) | Can the church establish what actually happened after a lost response and prove the restart did not repeat an external effect? |

Keep the same opaque person labels across all four workpapers. They belong to this exercise and have no meaning outside its organization. Times are UTC unless a row specifies a civil date. Treat the figures as expected results for the policy in each workpaper. An implementation can use different internal state labels if its observable decisions, dates, balances and access boundaries agree.

The register and finance workpapers can run concurrently after the opening identities are accepted. The bulletin depends on the certified audience and current purpose grants. Start the recovery exercise only after retaining the four evidence receipts specified there. A difference belongs to the owner of the underlying fact. Report how it changes the release decision as well as the number of affected records.
