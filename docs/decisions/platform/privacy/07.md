# Replay disclosure obligations independently of held evidence · cases 1729–2016

A restored original has an optional directory field, a preservation status and a distinct distribution artifact. The church has evidence for exactly the conditions listed. A hold protects the named restricted original, never granting public disclosure. Publication, prior distribution, archival retention and reopening are evaluated separately. If the historical obligations sequence is incomplete, the affected scope remains quarantined until the named authority verifies it; independent unrelated services can be released.
