## Interpreting the cases

All fixture identifiers are local to one case. An operation previously committed in one row is not a prerequisite for the next. For an event stream, the revision list is immutable; inputs vary delivery order and the starting consumer checkpoint. For financial values, a zero reflects a known quantity, while missing evidence defers an outcome. For publication, a hidden field has a separate decision from a lawful retention hold on its source. For any held workflow, a live owner exercises the next authorized decision.

Record the case ID, configured policy edition, actual decision, counted side effects, immutable outcome references and any unresolved disposition. Report a failure against the first differing owner. A rejected profile mutation, for example, cannot be treated as a satisfactory match if it still delivered an email or changed a financial balance.

This edition contains 16,960 worked decisions in 60 case pages. Each page has at most 288 cases.
