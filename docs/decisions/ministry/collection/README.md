# Can this adult collect the child now?

K is the named claimant; the child begins physically with the room lead. Grants and restrictions are closed at the start and open at the end. The recorded restriction has priority over a matching grant. All checks concern collection for this child and this session.

“Matched” means current identity and matching session credential. “Verified alternate” means the church’s documented replacement process and independent reviewer are complete. Missing evidence or unavailable current authority refers to the duty lead. No relationship, surname, payment or printed list can replace an authorized current decision.

A successful physical handover closes the chain once. A receipt retry on a closed chain cannot reassign custody. One evaluator checks ordered rules at each attempt and another constructs the set of minutes with a valid usable grant and identifies the first verified handover. Where both attempts are unsuccessful the child remains supervised.
