# Does the known birth evidence satisfy this age band?

Each assessment uses whole calendar years on the stated cut-off. The eligible band includes both endpoints. Birth evidence can be exact, month and year, or year alone.

Where a recorded 29 February has no anniversary in the assessment year, the displayed local administrative policy defines the effective birthday. A range clears only when every possible age fits. Every possible age outside the band produces an alternate-class route. Mixed evidence refers to authorized review, without inventing a birthday.

The interval result from the earliest and latest permitted birth dates is checked by enumerating every date allowed by the precision and comparing individual threshold anniversaries. Exact and partial cases include cut-off day, preceding and following day, leap boundaries and year end.
