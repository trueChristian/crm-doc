# Can this party take these seats?

Seats are numbered along one row. The two accessible positions can also be used as ordinary seats under this example policy. Free seats are the only seats available. Each request is atomic.

Require the requested number of accessible positions. For a companion request, the party needs at least one ordinary seat immediately beside one of its accessible positions. This casebook models one adjoining companion; other pairings need a separate allocation policy. “Together” requires a gapless run. A family accepting a split can use any distinct seats.

Choose the lexicographically smallest ordered set of acceptable seat labels. The result names the exact tickets and remaining inventory. Waiting changes no inventory. The oracle compares a combination search with an independent physical-seat mask evaluation. Cases with an unavoidable gross shortage are omitted so layout and accessibility can decide the result.
