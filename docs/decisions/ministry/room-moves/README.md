# Who owns P and Q after the room changes?

P and Q start in Room A. P already has one pending receiving place in Room B and remains under A’s care. B occupancy lists actual children only. Effective capacity is the smaller of room limit and present qualified staff times the local example ratio.

Q is an offered and physically witnessed direct handover; T accepts P’s held transfer; U changes staffing or the room limit. Each handover rechecks current occupancy, other children’s holds and the effective limit. A refused acknowledgement leaves the child in A, releasing P’s provisional seat if applicable. A capacity reduction never automatically moves a child already received.

The final result states each custodian, room counts and intake action. One evaluator uses occupancy balances; a second independently moves named members between sets and checks provisional occupants. A and B totals together must stay constant even if a new lower limit creates a staffed intervention.
