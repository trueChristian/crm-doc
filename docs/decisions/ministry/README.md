# Decide a ministry case

Use these worked cases to compare an observed outcome with the decision promised to a family, volunteer or church worker. Each row is a self-contained fixture under the stated church policy. Its short identifier follows its input values; changing a limit, date, claim or order of actions changes the case. These synthetic cases contain no personal church data.

## Use a case for acceptance

Select the decision route, read its fixture policy and choose a case page by the outcome under investigation. Start a fresh fixture with the exact listed facts. Where an action sequence is supplied, pause after each decision and collect the observable intermediate owner or balance. Compare the affected identities, inventory, eligibility, custody or open action against the expected row. Replaying a prior action must leave the same outcome for its original operation identity. A route can include valid referral, wait or escalation outcomes. A failed resource claim must leave previously authorized rights intact.

The 22,050 decisions are organized by outcome and paginated at 260 cases or fewer. Distinct inputs cover adjacent capacity thresholds, plausible unknown dates, grant boundaries, both orders of competing transactions, missing fifth weekdays, and unequal waiting, travel and workload constraints. Each route describes the calculation used to check its answers. A church may choose a different documented policy. Apply these expected results when it selects the corresponding rule edition.
