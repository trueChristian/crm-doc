# Individual awards, delivery, returns and outstanding authority

[All people decision cases](../README.md)

Each award is approved and funded. Opening gross is actual previously settled value or units; opening returns are confirmed against it. One pending reservation consumes authority but contributes nothing to net delivered. A new request reserves; only confirmation settles. “Replay settled” carries the original idempotency key even after a linked return. A larger new installment or excessive return is rejected without side effects. In this profile an authorized return reopens available authority; a separate closure or reduction needs approval. Never aggregate money, parcels, passes, credits and blankets together.

Check each figure with authority = net delivered + pending reservations + free authority. A second signed-movement calculation verifies both changes in net fulfillment and changes in reservations. The fund, currency, returning payee, and payee/beneficiary relationship must still pass the owning domain’s controls.
