# Age precision and eligibility

[All people decision cases](../README.md)

The named profiles are illustrative selection policies for the stated session date. Birth evidence must support the entire inclusive age band before approval. If all possible ages fall outside it, return outside. Mixed results require review. An approximate year without an uncertainty interval is unbounded. Exact leap-day birthdays use the March 1 anniversary in non-leap years for this profile; institutions may configure another rule. Personal disclosure and other participation requirements are separate. Declared future exact verification is never available to the initial evaluator.

Boundary cases cover both edges of bounded bands, year transitions, leap day, different month lengths and dates near a cut-off. Independent validation enumerates every possible date in each finite initial interval and compares all resulting qualification decisions.
