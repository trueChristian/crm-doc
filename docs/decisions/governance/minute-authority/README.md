# Minutes corrections, stays and authority already consumed

[All decision profiles](../README.md) · [Clerk procedure](../../../handbook/governance/minutes-and-review.md)

All values are in the same illustrative currency. Commitments were already validly recorded and remain unchanged by the clerk's decision. The test separates the governing decision, face value of an issued extract, residual committed exposure, and whether new money may actually be authorized.

## Reproduce the cases

1. Select the effective governing amount for this case and ruling stage. Only the actual competent decision can change it.
2. Calculate unused arithmetic capacity as max(0, authority − already committed). Calculate excess exposure as max(0, committed − authority). Preserve both original commitments and the older evidence.
3. If an authorized stay applies, release capacity is zero even when the arithmetic balance is positive. Determine whether the issued document is current, requires correction, or awaits a linked replacement; never revise a bank posting here.
