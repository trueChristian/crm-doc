# Quorum under vacancies, recusals and representation minima

[All decision profiles](../README.md) · [Clerk procedure](../../../handbook/governance/roll-and-quorum.md)

The headcount column includes present people who declared a disqualifying interest on this item. The proxy column counts absent eligible principals whose holder is present and eligible. The two categories are disjoint. Districts denote personally present non-recused representation.

## Reproduce the cases

1. Resolve the charter-defined eligible denominator; exclude vacancies or recused seats only under the named rule.
2. Calculate the ceiling of denominator times the rule's fraction. Count present less recusals plus proxies only where permitted.
3. Test the count and required representation separately. Check the numerical result again by multiplying both sides of the inequality using integers.
