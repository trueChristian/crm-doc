# Proxy conflicts, personal arrival and consumed rights

[All decision profiles](../README.md) · [Clerk procedure](../../../handbook/governance/roll-and-quorum.md)

The table concerns one principal's single entitlement. Other existing holder mandates affect only the cap. Prior attempt means one ballot presentation subject to the same rules, which consumes the right only if an eligible actor could cast at that instant. The check is read immediately after any simultaneous presentation. A future attempt recorded in the test schedule has no effect at the check.

## Reproduce the cases

1. At 18:20 accept the initial mandate when existing holdings are below the policy cap. Both principal declaration and holder suitability apply to use at the decision instant.
2. At the prior attempt, independently reconstruct the active exercising actor using presence, revocation, conflicts and policy. Only a permitted exercise consumes the right.
3. At check time resolve any already effective changes, then return the consumed status first. Otherwise identify the actor or the actionable blocker. Pending or prior refusal cannot create a second right.
