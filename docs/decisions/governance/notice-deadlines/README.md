# Formal notice windows and deemed service

[All decision profiles](../README.md) · [Clerk procedure](../../../handbook/governance/notice-control.md)

Compare actual dispatch, effective service, clear-day interval and latest dispatch separately. The example holidays and deemed service rules are fictional policies.

## Reproduce the cases

1. Count backwards from, and excluding, the meeting date. Reserve N qualifying clear dates. The preceding qualifying day is the latest effective service day.
2. Subtract the configured delivery lag on the same calendar to obtain the dispatch deadline; compare the actual dispatch with it.
3. Independently count qualifying dates strictly after actual service and strictly before the meeting. The two tests must agree. A late result identifies an exception and cannot create a waiver.
