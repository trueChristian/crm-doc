# Verify captions and accessible church releases

An editor receives a 60-second recording. The church permits a public edit containing source intervals [0,12), [18,30) and [40,60) seconds. The removed portions include an in-room-only testimony. The approved public edit lasts 44 seconds. Caption providers may prepare the timed text, but the church's reviewer authorizes the wording, speaker attribution and accessible edition for this audience. Each interval includes its start and excludes its end.

| Source cue | Expected public result |
| --- | --- |
| A welcome, [1,5) | Display at [1,5). Preserve the verified spelling of the speaker's name and any agreed translation. |
| A sentence crossing the first cut, [10,20) | Retain fragments at [10,12) and [12,14). Review the actual words in both surviving segments. Repeating the complete original sentence could disclose words from the cut. |
| An in-room-only name, [12,18) | Omit the name, cue, index entry and speaker label. Its end coincides with a surviving boundary but it has no surviving duration. |
| A greeting after the second cut, [40,44) | Display at [24,28). A search result and any chapter link for the public edition use the new timeline. |
| An accessible description spanning both cuts, [8,45) | Three retained fragments belong at [8,12), [12,24) and [24,29). The reviewer checks that visible wording accurately describes the edited scene and discloses no withdrawn detail. |
| The provider returns an older caption edition after the new edit has been approved | Hold the return for edition review. It cannot overwrite approved text, timing or the destination audience. |

The editor checks playback with captions on, an accessible transcript, the search result and any downloadable transcript as a public visitor. A viewer with a valid members-only grant receives only the edition approved for that audience. After a speaker withdraws permission, reevaluate all controlled language renditions and searchable text. A withdrawn public edition stays unavailable while a replacement translation awaits approval.
