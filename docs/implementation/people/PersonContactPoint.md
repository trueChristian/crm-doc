# PersonContactPoint

[Personal register and identity resolution](../../people/personal-register.md) · [Department records](README.md) · [Value conventions](../value-conventions.md)

## Record invariant

Identity, audit fields, ownership and effective-date notation follow the [shared record envelope](../../foundation/record-conventions.md). A business key or parent-child uniqueness rule below remains enforceable even when an implementation also assigns an opaque identifier.

Multiple contact points per person. A shared telephone or mailbox is valid on multiple records. Verification establishes reachability, distinct from consent to receive a particular communication. Postal values can reference an effective household address through its identifier where applicable.
