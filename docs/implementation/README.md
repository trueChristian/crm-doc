# Record and field specifications

Each record has a separate page. The field inventory preserves its business declaration, including optional markers, enumerated choices, named target records and relationships. The probes distinguish an interpretable input from permission to commit a business action. A scoped reference with an owner-defined target is kept distinct from a typed relationship.
