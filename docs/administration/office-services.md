# Front office, public information and lending

The office receives calls, walk-ins, emails, paper forms and anonymous enquiries. A visitor should be able to learn the next service time or request an accessible appointment without joining the directory. A church can also lend books, study kits, instruments and accessibility equipment. Retain a clear distinction between an item on loan, an item for sale and an asset on the financial register.

**Public office controls.** Support alternate text, local language and low-bandwidth service notices. A content owner previews the exact audience and expiry, an authorized publisher approves, and an expired location or programme displays an updated route to the current information. A family page and printed visitor card can show the same public contact without exposing private directory details.

**Acceptance.** A request for a safe callback routed to a pastor shows the receptionist only the referral status. A public visitor can find a wheelchair-accessible entrance and the service language from the event or campus page. A book checked in while an overdue notice is queued produces no incorrect reminder. Returning a kit with one missing item opens a condition exception and preserves the originally issued contents. A closed office request leaves any separately accepted care case under its own owner.
