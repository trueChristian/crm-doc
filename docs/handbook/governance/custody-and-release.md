# Custody, release and correction of church archives

An archivist must be able to account for an original volume, each independent digital copy, any restricted extract and every transfer of physical custody. An approved minute, a physical volume and a scan are different records. The [archive register](../../administration/archives.md) controls the holdings and the [privacy register](../../platform/privacy-records.md) controls holds and disposal decisions.

## Accession and custody

Inspect the physical item with the donor or transferring custodian where possible. Capture the accession identifier, collection, title, provenance, date range and precision, owner or deposit terms, permitted uses, condition, location, restrictions, evidence and accession date. A volume with uncertain historical provenance or dates retains that uncertainty. Select its preservation master, working copy and public derivative separately. Record checksums, byte counts, media type, chronology, capture operator and links to the actual original pages. An exactly matching file proves bit identity against a trusted earlier digest; it does not prove authorship, accuracy or release authority.

Custody follows acknowledged events. A proposed loan names borrower, purpose, authority, permitted material, due time, release conditions and intended return location. Complete the outgoing handover to establish actual custody. A second request while a loan is active cannot become a second release. When a borrower returns a volume, compare seal, condition, intake count and location, obtain the receiving custodian's confirmation and close custody. Overdue, missing and damaged are separate dispositions. An item reported missing still belongs in the finding aid and inventory for authorized custodians. The history identifies the last person confirmed to have held it and any subsequent unverified account.

## Worked chain and fixity failure

| Stage | Evidence | Deterministic result |
| --- | --- | --- |
| 1 May, accession B7 | Volume B7, leaves 1–96, two restricted inserts and one fold-out map, location vault A | Inventory counts separately catalogued inserts and notes the fold-out; public description omits the sensitive insert titles. |
| 3 May, digitization | Master C1 with 99 captured objects under this manifest; verified preservation replica C2 | Each file has digest and length, and the ordered collection manifest has its own digest. C1 and C2 verify against the same protected accession evidence. |
| 12 June, loan | Authorized clerk borrows original B7, return due 17 June | B7 is on loan. C1 and C2 remain in digital custody; a concurrent loan is rejected or queued. |
| 17 June, return | Borrower returns it; custodian finds one insert missing | Keep a discrepancy and restricted incident evidence. Do not certify complete return while the missing item remains unresolved. |
| 20 June, scheduled fixity check | C1 disagrees at object 44; C2 matches the earlier trusted digest and protected manifest | Quarantine suspect C1. Check replica, bytes, manifest and prior verification independently; create a replacement copy with provenance, recheck and document who accepted it. Never redefine the expected digest merely to match the damaged file. |
| 21 June, reader request | Researcher requests public minutes and private insert | Review the permitted scope, produce a separately identified released copy or refusal and record permissible reason. The reader does not receive a master merely because the main volume is public. |

If both copies disagree with the trusted digest, preserve the suspect copies, mark verification failure and investigate additional independently verified preservation copies or rescan the original with new provenance. A reconstruction has its own identity and limitations; it cannot be represented as the original bitstream. A physical insert recovered after the loan requires a new acknowledged return and condition assessment.

## Issue and verify an extract

Authenticate requester or representative, establish purpose and allowed fields, select the authoritative edition and page, and record the clerk or archivist permitted to certify. Prepare a derived copy, remove restricted underlying text and metadata as well as rendered marks; check attachments, thumbnails, layers, embedded comments, file names, optical text and bookmarks. Test the delivered file with extraction and search appropriate to its format. A second reviewer compares the output to the approved release scope before sign-off. Assign a non-reused serial and receipt reference. A verification request reveals only permitted issued/replaced/revoked status and minimum identifying information. Do not expose a search service for private register names.

## Retention and exit tests

Capture the controlling retention class, start event, review date, all applicable holds, decision authority and custody of controlled copies. Immediately before disposal recheck every active hold, outstanding appeal, permanent-preservation rule and previously issued extract. Two overlapping holds must both be resolved. A released hold cannot delete content by itself. Where destruction is authorized, document the authorized scope, execution date, method, independent evidence and minimal enduring record; apply corresponding treatment to derived search, previews, caches and backups under their retention policy.

A late correction to an underlying register entry marks affected issue serials for review. Issue a replacement only to authorized recipients, preserve the predecessor status and show recovery or correction attempts for already distributed copies. The departing archivist hands over active loans, holds, pending access requests, unreconciled physical discrepancies, preservation check schedules and custody of verification material to the next authorized officer. A successful drill lets that officer find B7's current custody and supply an approved version without opening either confidential insert.
